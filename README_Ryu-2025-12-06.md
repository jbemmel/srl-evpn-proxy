# Ryu Status Overview

This note summarizes the current state of the **Ryu SDN framework** based on publicly available information.

## Project Activity
- The most recent version published on PyPI is **4.34**, released on **May 27, 2020**.
- The main GitHub repository has had **no commits for roughly three years**.
- The repository explicitly states that **Ryu is not currently maintained** and is seeking new maintainers.

## Security Considerations
- Version 4.34 — as well as earlier versions — has **known vulnerabilities** listed in security-tracking databases.
- With no active maintainers, these vulnerabilities remain unresolved.

## Community & Ecosystem Status
- Major downstream users, including **OpenStack Neutron**, have migrated away from Ryu due to its maintenance status (moving to **os-ken**).
- Broader SDN and automation communities show similar trends.

## Summary
Ryu is still functional and documented, but the project is effectively unmaintained. Anyone considering it for new work should weigh stability and security risks and evaluate maintained alternatives.
